## 🔬 Research Experience

### Summer Research Intern | IIIT Vadodara
**June 2025 – August 2025**

Working on **uncertainty-aware deep learning** for multi-label classification:

- 🎯 Developed similarity-based multi-label classification using **Rough Entropy Theory (RET)** to effectively capture uncertainty in ambiguous samples
- 🧠 Designed novel embedding learning methods that emphasize ambiguous samples, significantly improving model understanding and performance on challenging datasets
- ⚡ Created a RET-weighted contrastive loss function within a Siamese neural network architecture to prioritize learning from ambiguous sample pairs
- 📊 Implemented and rigorously evaluated computational models using **PyTorch** on Scene and Flags benchmark datasets
- 🔍 Focus: Bridging rough set theory with modern deep learning to enhance model robustness in uncertain scenarios
